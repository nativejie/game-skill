# 无聊与挫败：症状、原因、修法

调参时逐项对照。左边是玩家的表现，或者模拟报告里能看到的信号。

## 无聊

| 症状 | 常见原因 | 修法 |
|---|---|---|
| 进来看了一分钟就走 | 第一个奖励来得太晚；不知道该干什么 | 30 秒内给第一次升级或掉落；屏幕上常驻「现在可以发什么」 |
| 玩了十几分钟后走 | 中层奖励（3–5 分钟一次）空了；升级间隔越拉越长 | 模拟里看「最长没好事时长」；加中层奖励（事件结算、阶段掉落）；奖励按等级百分比给，间隔就不会随等级变长 |
| 数字在涨，但没感觉 | 涨得太平滑；加成看不见 | 跨大台阶时做大反馈（突破、换颜色、全屏播报）；属性加成在画面上体现 |
| 货币攒了一堆不知道干嘛 | 消耗不够或价格太低 | 模拟里看货币余额曲线；加有吸引力的消耗（外观、抽奖、升阶）；把价格换算成「几小时收入」再定 |
| 抽到的都是重复的 | 池子小、没有重复转化 | 重复转成碎片或通用货币；优先给还没有的 |
| 每天来做的事都一样 | 只有一种循环 | 事件轮换；每日 / 每周目标；限时活动 |
| 满级以后没事做 | 只有一条成长线 | 加横向收集线（外观、宠物、图鉴）和社交线（排行、公会） |
| 一路顺风，没有紧张感 | 没有失败可能 | 加有成功率的关键节点（突破），失败有损失但有保护道具 |

## 挫败

| 症状 | 常见原因 | 修法 |
|---|---|---|
| 「我怎么一直抽不到」 | 纯随机，没有保底 | 保底（第 N 次必出）、伪随机（每次失败概率上升）；看最倒霉 10% 的玩家 |
| 卡在某一级很久 | 曲线在那里突然变陡；或者要的道具只有一个低概率来源 | 曲线做平滑过渡；关键道具至少两个来源，其中一个是确定的 |
| 「输了什么都没有」 | 竞猜 / 选择类玩法没有安慰奖 | 参与就有奖，赢了更多；不押玩家的资源 |
| 新人被老玩家碾压 | 奖励按绝对伤害分，或者只奖第一名 | 奖励按百分比、按参与；分段排行；最后一击 / 幸运奖这类和实力无关的奖 |
| 离开一会儿就落后很多 | 只有在线才有收益，或者有衰减惩罚 | 离线有少量收益；不设离线惩罚；回归有补偿 |
| 失败损失太大 | 失败直接扣大量进度 | 损失有上限；有保护道具；失败也给一点东西 |
| 规则看不懂 | 机制太多、隐藏数值 | 每个事件一句话说清楚；关键数字直接显示 |
| 付费玩家把一切都拿走 | 稀缺奖励只给付费 | 免费路线能拿到所有中档内容；顶级奖励里也留几个靠时间和运气的 |

## 太快玩完 / 太肝

| 症状 | 信号 | 修法 |
|---|---|---|
| 一两天就满级 | 模拟里满级时间远小于目标总时长 | 降奖励比例或加陡曲线后段；加横向收集线 |
| 每天要玩很久才能完成 | 每日目标需要的时长超过单次会话时长 | 每日目标控制在一次会话内能完成；挂机代替重复操作 |
| 不同人数的房间体验差很多 | 奖励按总量分，人越多每人越少 | 按每人输出估难度（例如 BOSS 血量 = 在座输出 × 目标时长） |

## 检查顺序

1. 跑模拟，先看三个数：第一次好事的时间、最长没好事时长（最倒霉 10%）、到达关键等级的时间。
2. 看货币余额曲线：一直涨还是一直为零。
3. 对照上面三张表，挑最严重的一条改。
4. 一次只改一两个参数，再跑模拟，把改动和前后结果记下来。
