# 直播画面与交互

## 画面布局（竖屏 1080×1920）

自上而下：
1. **标题 Logo**。
2. **轮播横幅**：每 6 秒换一个榜（修为、货币、贡献、击杀、破阵、BOSS 伤害、收藏）和一页「玩法」（列出主要指令）。榜单是不花钱的社交激励，也顺便教新观众指令。
3. **状态条**：本场最高境界 + 名字、在座人数 `30/30`。
4. **事件栏**：左边是当前事件的一句说明，中间是宗门 / 地图名牌，右边是事件名 + 倒计时 + 指令提示。等待中显示「下次事件」，结算中显示「结算奖励」。观众随时进来，看事件栏就知道现在能发什么。
5. **棋盘**：30 个编号席位（6 行 × 5 列）。每个席位有头像圆框（颜色按大境界）、竖排境界牌、属性数字（攻 / 速 / 货币）、称号牌、宠物、翅膀 / 光环、编号 + 昵称。
6. **底部**：事件专属的栏（例如 BOSS 血条栏），以及飘过的播报。

礼物入口不进游戏画面，由主播叠加。

## 席位就是观众的「个人空间」

- 外观品阶直接画在席位上：灵品名字变色、仙品柔光、神品环绕光点且头像放大 10%、至尊旋转光芒并在入座时全屏播报。观众花了时间或钱，大家都要看得见。
- 「背包 / 幻化 / 灵宠 / 排行」这类查询，只在自己席位上方飘两行摘要，新的替换旧的；顶排的摘要要避开 HUD。**不弹大面板**：直播画面是大家共享的，一个人的面板会挡住所有人。（这个项目先做了面板卡片，用户指出后整套删掉了。）
- 同一个观众的大提示要限频（例如 45 秒一次），否则刷屏时棋盘一直被挡。

## 打怪（主事件）的反馈要大

- 怪从两侧飞入，在棋盘上游走，头顶「编号.名字 Lv」和血条。字母编号让「a编号」可以指定攻击。
- 每次攻击：施法者头顶法阵 + 气流弹道飞向目标 + 命中爆光 + 伤害数字。每第 N 击是大招（光柱落下、伤害 ×2.5）；15% 暴击，数字更大更黄。
- 最后一击弹出卡片「击败妖兽 灵气+N 灵石+N」，助攻者按伤害分成。
- 数字用直播间习惯的写法：`18988`、`2.2w`、`965.9w`、`1.3亿`。大数字本身就是反馈。
- 外观要影响战斗表现（幻剑换弹道颜色和剑身，特殊剑有双影、巨剑、全场剑阵），这是外观最直接的价值。
- 低配开关（弱特效）留着。

## 指令设计

- 两个字的动词，容错：`ak`、`a k`、`A K`、`攻击k` 都是指定攻击；`服用 聚气丹` 和 `吃聚气丹` 都行。
- 数字按当前事件解释：幻阵里是阵位、商店里是货架、夺宝里是宝箱。
- 带名字的指令（`幻化 青竹客`、`灵宠 火麒麟`、`喂养 灵草`）自动识别类别。
- 未入座时发其它指令，回复「先发 加入 入座」。
- 自动化减少刷屏：发一次「击退」后自动攻击；世界BOSS 时在座全员自动出手，不用发指令。
- 弹幕有零点几秒到几秒的延迟：不做比反应速度的玩法，需要回应的窗口至少 8 秒，倒计时结束后多收一两秒。
- 每场直播统计「未识别弹幕」排行，把高频的写错（「机退」「jt」）补成别名（`streamer-ops.md`「数据复盘」）。

## 事件设计要点

- 每个事件要让「什么都不发的人」也能有点收获（挂机、自动出手），让「发弹幕的人」收获更多。
- 选择类事件（选阵、选宝箱）不押资源：参与就有奖，赢了奖更多，输了有安慰奖。
- 整屏事件（例如五行幻阵）可以盖住棋盘，但要有：滚动剧情、规则框、回合面板（第 N 回 · 第 x/3 轮 · 倒计时）、各选项人数、加入飘条、历史统计（近 100 / 20 轮）、参与记录。观众中途进来也能看懂。
- 结算卡片显示本场榜单前几名，避开画面上的重要区域。

## 宗门 = 直播间

- 一个直播间就是一个宗门，主播在控制台建宗 / 改名；没建宗时牌匾显示「未建宗」，提示主播建宗。
- 观众的各种行为累积贡献 → 宗门等级 → 全员挂机加成。这是让观众对「这个直播间」产生归属的机制。
- 跨直播间排名、宗门战需要服务器，先留接口（排名手动填）。

## 社交与送礼（来自上班案例）

这一节是上班主题项目里用户定下、并已实现的做法。它们是设计判断，还没有真实观众数据验证。

- **阵营用观众自带的身份。** 行业、城市这种观众本来就有的身份当阵营，入座时顺手带上（`上班 互联网 上海`），榜单按人均算，人少的阵营也有机会。用户判断「扣1扣2」「熊猫推推」这类临时阵营勾不起付费：没人在乎自己临时站哪边。
- **点名对手要能反击。** 甩锅这种点名玩法，被点的人要有足够长的反击窗口（弹幕有 0.5–3 秒延迟，留 8 秒），并在工位上写清「XX 甩的」、下次提醒「仇人 XX」。被点名而无法回应，只剩挫败。
- **送礼人要被看见，但不要变强。** 送礼累计（最近 30 天滚动）换成身份等级：工牌底板、头顶徽章、播报前缀、当天最多的人有皇冠；高等级每天第一次送礼时有入场仪式（全屏横幅、老板出门鞠躬），礼物效果上署名。**不给**免抓、免惩罚、数值加成、点名权，唯一的实际特权是满座时不被换座。这样送礼的虚荣心有地方放，不送礼的人也不觉得被碾压。
- **身份名字和成长名字分开。** 送礼等级和摸鱼升上去的职级不能用同一套词（例如都有「合伙人」），否则观众分不清头衔是怎么来的。上班主题用「甲方」系列：老板唯一要点头哈腰的人就是甲方。
- **礼物只触发效果，不改规则。** 不做押注类玩法，不做礼物换随机大奖；礼物入口不进游戏画面，由主播叠加。价位梯度、连击合并、效果队列、免费互动和合规见 `gifts-and-compliance.md`。
- **满座换座。** 坐满后，闲置超过 10 分钟的座位让给新来的人（优先闲置最久的；手上有锅、冲刺期间不换）。否则直播间越热闹，新观众越进不来，新来送礼的人还白送。
- **手机可读性。** 画面在手机上缩小约 2.8 倍，关键社交信息（谁甩的锅、谁送的礼）在 1080 宽度下不小于 20px。验收方法见 `art-pipeline.md`「手机视角验收」。
